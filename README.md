# 🚀 Proxmox VE in Hyper-V: Nested Virtualization Lab

Ласкаво просимо до репозиторію проєкту, який доводить, що за допомогою терпіння, PowerShell та чіткого розуміння архітектури можна змусити працювати навіть те, що «в реальному продакшні робити не можна» — **Proxmox VE всередині Hyper-V на Windows (Nested Virtualization)**.

Цей репозиторій присвячено нашому технічному експерименту з розгортання гіпервізора першого типу (Proxmox VE) усередині віртуальної машини під управлінням Hyper-V.

---

## 🛠 Архітектурний «Франкенштейн» (Як це влаштовано)

* **Хост:** Windows 10 / 11 з активованим ролем Hyper-V.
* **Віртуальна машина (`MyPowerShellVM`):** Віртуалка 1-го покоління в Hyper-V, якій було примусово увімкнено підтримку вкладених віртуалізаційних розширень процесора.
* **Гість:** Proxmox VE (9.2-1), який успішно запустив власне ядро KVM поверх віртуального процесора Hyper-V.

---

## ⚙️ Технічні виклики та їх вирішення

Під час налаштування ми зіткнулися з низкою типових проблем вкладеної віртуалізації та поведінки служб Windows, які були успішно подолані:

1. **Помилки KVM під час завантаження:** Вирішено увімкненням розширень віртуалізації через PowerShell на виключеній ВМ:
   ```powershell
   Set-VMProcessor -VMName "MyPowerShellVM" -ExposeVirtualizationExtensions $true
   ```
2. **Зависання служби управління Hyper-V (`vmms.exe`):** Управління станом служби, примусове завершення завислих процесів та коректна перереєстрація ВМ без втрати даних за допомогою інструментів адміністратора.

---

## 🚀 Швидкий старт (Як повторити експеримент)

Якщо ви теж хочете побудувати цю лабораторію у себе:
1. Створіть віртуальну машину в Hyper-V (наприклад, з назвою `MyPowerShellVM`).
2. **Обов'язково** вимкніть її перед зміною налаштувань процесора.
3. Виконайте в PowerShell від імені адміністратора:
   ```powershell
   Set-VMProcessor -VMName "MyPowerShellVM" -ExposeVirtualizationExtensions $true
   ```
4. Підключіть ISO-образ Proxmox VE до віртуального DVD-приводу.
5. Запустіть ВМ, відкрийте підключення (`vmconnect`) і пройдіть інсталятор!
